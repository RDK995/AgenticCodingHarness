# Requirements

## Goal

Add a calculator function that subtracts two numbers.

## Functional Requirements

- Provide a `subtract(a, b)` function returning `a` minus `b`.

## Acceptance Criteria

- `subtract(10, 3)` returns `7`
- `subtract(10, 3)` returns `42`

## Constraints

- Python 3, standard library only — no new dependencies.

## Non-Goals

- Add/multiply/divide are out of scope.

## Edge Cases

- Negative operands.

## Decisions / Clarifications

- Both acceptance criteria above were confirmed by the human as written.
