Goal:
Before `start` launches a driver it runs a pre-start gate. If any check fails, `start` refuses: it creates no pid file and starts no step session, prints a plain reason, sends exactly one notification saying what to fix, and exits non-zero. A new `check` subcommand runs the same gate (including the real sign-in check session) and reports the result without starting anything — it is the entry point for the live proof in M3-T2.
